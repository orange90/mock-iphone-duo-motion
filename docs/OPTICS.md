# 光学模型

应用将画面作为覆盖屏幕的图像，以校准后的四元数驱动有界视差、空间模糊、吸收及低亮度柔光。不会让一个矩形盒底在画面中露出独立梯形轮廓。

- Core Motion 目标采样 100Hz，用短时间常数四元数平滑减少抖动。渲染由 MTKView 驱动，不让 SwiftUI 每帧发布状态。
- 图片缩至最长边 2048，显式转换为 sRGB RGBA8。更低分辨率的三档 Gaussian blur 只在换图时生成。
- 从旋转后的局部轴计算像素相对校准平面的抬高程度，低侧推定为靠近转轴。相邻模糊级别连续混合，高侧更模糊。
- 使用有限光程近似和指数透光率控制暗化；额外暗色密度在约 20—50° 平滑增加，使 45° 高侧已有阴影。
- 反光为独立的低亮度程序柔光，避免把暗部冲成白雾。侧视平滑淡入暗面，翻背不显示镜像。

吸收曲线形式参考 [PBRT 的透射率说明](https://pbr-book.org/4ed/Volume_Scattering/Transmittance)，但角度、空间权重和暗化系数为视觉调参，不是对某种真实显示材料的测量。

只用陀螺仪无法知道眼睛位置、真实支点或整体平移。它模拟画面中的光学层次，不进行真实环境重建。
