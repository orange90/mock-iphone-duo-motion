# 验证范围

当前版本：1.8。开发验证环境为 Xcode 26.5、iPhone 模拟器 / iOS 26.5；真机原型已在 iPhone 11 / iOS 18.7.8 安装运行。

现有 16 项 XCTest 覆盖：

- 图片最长边限制、EXIF 方向归一化、损坏数据、sRGB RGBA 通道及行方向。
- 旧设置读取；旧版效果字段不会恢复已移除的严格投影模式。
- Metal 着色器和预模糊纹理初始化、Uniforms 内存布局。
- GPU 翻转有限性、背面、360° 恢复；俯仰/侧转/斜向每 1° 扫描至 90°。
- 分离验证空间透光率与模糊梯度，检查 45° 显示编码后的暗化。
- 手持校准在 30/60/100Hz 下容忍轻微抖动；拒绝明显转动、过期和过短数据，支持取消和重复请求保护。

另外，`Scripts/test-math.sh` 运行 28 项历史空间数学检查，其中包含 7,578 条射线。部分检查针对保留的旧版几何辅助代码；应用现在只提供光学外屏。

目标渲染速率为 60fps，尚未完成各机型持续三分钟的温升、GPU 耗时或端到端延迟测量。提交帧率日志不是完整性能测量。模拟器截图和自动测试不能证明裸眼效果与参考视频完全一致。
